# Audit : frontière back/front des règles métier

Date : 18/11/2026. Références : back `main` `ebaabd2` (OpenAPI v1.11.0), front `main` `b2effca`. Les deux versions ont été vérifiées sur `main` avant l'audit.

Couverture : tous les modules back (`players`, `meta`, `items`, `builds`, `groups`, `tracked-players`, `catalog`, `auth`, cache, client Deadlock). Côté front, les dix fichiers demandés ont été lus, ainsi que leurs consommateurs (`hooks.ts`, `useMatchEnrichment.ts`, `HeroesTab`, `GroupDetailPage`, `RankProgress`, `RankModesWidget`). Je n'ai pas vérifié de façon exhaustive que les composants `Histogram`, `Donut` et `LineChart` n'ont aucun consommateur.

## 1. Calculs et enrichissements recensés

Pour chaque ligne : fonctionnalité, source, calcul front, équivalent back, risque de divergence, coût en requêtes, cible, priorité, impact OpenAPI et migration.
